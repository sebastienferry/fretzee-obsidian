# Tablature presentation and chord progressions

## Why
Users need compact Guitar Pro excerpts at a chosen zoom and readable chord grids directly in notes using their existing key/value examples.

## What changes
- Support optional zoom, minimal and title for tablature blocks in JSON or simple flat key/value syntax.
- Render chords blocks containing optional title/key metadata and pipe-delimited progression rows.
- Preserve existing references, selections and offline behavior and distribute version 0.4.0.

## Impact
Obsidian block parsing, AlphaTab display settings, semantic chord-grid HTML, documentation and installed plugin assets. No source-file or note rewrites.

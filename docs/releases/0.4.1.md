# Fretzee 0.4.1

First public release for Obsidian desktop 1.14.5 and newer.

- Render Fretzee JSON diagrams and complete Studio sheets, including four-column layouts.
- Choose a vault Guitar Pro file, track and inclusive measure range for an offline excerpt.
- Customize excerpts with zoom, minimal headers and explicit titles using JSON or flat key/value options.
- Display literal chord and roman-numeral progressions in aligned `chords` grids.
- Work without a Studio account, network requests, playback or telemetry.

Install through the attached ZIP, or place main.js, manifest.json and styles.css in your vault's plugins/fretzee configuration folder. Enable Fretzee in Community plugins. The Community directory submission is being prepared; this release does not claim directory approval.
